# Card images

Drop card artwork here, named to match each card's `image_path` (defaults
to `<card_id>.png`, e.g. `dark_magician.png`) unless a card's YAML entry
sets an explicit `image:` filename.

Any card whose image file isn't present here falls back to the CardViewer's
built-in "No Image Available" placeholder — nothing needs to be filled in
before the game can run.
